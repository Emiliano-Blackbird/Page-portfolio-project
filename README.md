# 🧑‍💻 Page-Portfolio-Project

Un portfolio moderno, responsive e instalable inspirado en el diseño de Adam Keyes. Este sitio destaca tus habilidades, proyectos y experiencia como desarrollador. Pensado desde el diseño Mobile First y optimizado para ofrecer una experiencia visual atractiva y profesional.

🔗 GitHub Pages Demo: https://emiliano-blackbird.github.io/Page-portfolio-project/

## Características

    🎨 Estilo moderno y minimalista
    ⚡ Desarrollo con Vite para carga ultrarrápida
    📱 Diseño 100% responsive (Mobile First)
    🌈 Animaciones y transiciones suaves
    🎯 Secciones de experiencia, proyectos y contacto
    🔒 Accesibilidad optimizada
    💼 Lista de proyectos con links a código y demo

## Tecnologías

    HTML5 + SCSS (Sass Modular)
    JavaScript (ES Modules)
    Vite
    Font Icons personalizados
    Google Fonts: Inter, Exo
    Diseño Responsive con media queries y mixins Sass

## Cómo utilizar

Clona el repositorio y lanza el proyecto localmente:

git clone https://github.com/Emiliano-Blackbird/page-portfolio-project.git
cd page-portfolio-project
npm install
npm run dev

    Asegúrate de tener Node.js y Vite instalados.

## Secciones del Portfolio

    Header: Nombre + links sociales

    Hero: Presentación personal

    Experience: Lista de tecnologías y años de experiencia

    Projects: Galería de proyectos con botones para ver demo y código

    Contact: Formulario de contacto funcional (pendiente de integración con backend si se desea)

    Footer: Navegación social + branding
